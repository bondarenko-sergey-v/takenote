# Run Client

Use this flow to run only the client dev server.

1. Install dependencies.

   ```bash
   npm install --cache /tmp/takenote-npm-cache
   ```

2. Start the client.

   ```bash
   npm run client
   ```

3. Open `http://127.0.0.1:2990` in your browser.
4. Stop the dev server with `Ctrl+C`.
