# Run Client

Use this flow for the client-only demo. For the full self-hosted app, follow `README.md` and run `npm run dev`.

1. Install dependencies.

```bash
npm install --cache /tmp/takenote-npm-cache
```

2. Start the client.

```bash
npm run client
```

3. Open `http://127.0.0.1:2990`.
4. Stop the client with `Ctrl+C`.
